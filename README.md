# 서블릿부터 JSP, 그리고 스프링부트까지: 스프링 MVC 학습 프로젝트

이 프로젝트는 서블릿, JSP, 그리고 스프링부트에서 제공하는 애노테이션을 활용한 스프링 MVC 프레임워크를 학습하기 위한 저장소입니다. <br>
각 기술을 단계적으로 학습하며, 서블릿 기반의 간단한 웹 애플리케이션에서부터 스프링부트 기반의 더 복잡한 웹 애플리케이션까지 구축할 수 있도록 돕는 예제 코드가 포함되어 있습니다.

## 📚 학습 목표

- **서블릿(Servlet)**: HTTP 요청을 처리하는 기본적인 웹 기술을 익히기.
- **JSP**: 자바 서버 페이지(JSP)를 사용하여 동적 웹 페이지를 생성하고, 서블릿과 함께 사용하기.
- **스프링 MVC**: 스프링부트에서 제공하는 애노테이션을 활용한 스프링 MVC 웹 애플리케이션 구조 이해 및 구축.
